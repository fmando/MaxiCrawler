# Shared archive links

Collected from the mailing list. Nothing here is downloaded; the links are only
catalogued.

## Modern format

- Full backup (file):
  https://mega.nz/file/AaBbCcDd#0123456789abcdefghijklmnopqrstuvwxyzABCDEFG
- Photo collection (folder):
  https://mega.nz/folder/QwErTyUi#0123456789abcdefghijkl
- One picture inside that folder:
  https://mega.nz/folder/QwErTyUi#0123456789abcdefghijkl/file/N0d3H4nd
- A subfolder inside it:
  https://mega.nz/folder/QwErTyUi#0123456789abcdefghijkl/folder/Su8F0ld3

## Legacy format

The same archive was originally shared with the old scheme:

- https://mega.nz/#!ZzYyXxWw!0123456789abcdefghijklmnopqrstuvwxyzABCDEFG
- https://mega.nz/#F!1a2B3c4D!0123456789abcdefghijkl
- https://mega.nz/#F!1a2B3c4D!0123456789abcdefghijkl!N0d3H4nd

And one from the era of the previous domain:

- https://mega.co.nz/#!L3g4cY01!0123456789abcdefghijklmnopqrstuvwxyzABCDEFG

## Repeated links

The full backup is listed a second time on purpose, so duplicate handling can
be observed: https://mega.nz/file/AaBbCcDd#0123456789abcdefghijklmnopqrstuvwxyzABCDEFG

Two legacy links that differ only in their handle must stay distinct — dropping
the fragment would make them look identical:
https://mega.nz/#!D1ff3r3n!0123456789abcdefghijklmnopqrstuvwxyzABCDEFG

## Links without a key

A share published without its decryption key: https://mega.nz/file/N0K3Yy00

## Not shares

These are ordinary pages on the same host and must fall through to the generic
plugin: https://mega.nz/pro and https://mega.nz/about

## Malformed

Neither of these is a usable share link:

- https://mega.nz/#!  — a legacy marker with nothing after it
