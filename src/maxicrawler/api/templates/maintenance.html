Runs over the whole library

The interface answers a question at a time; these ask one of the whole shelf. They are run from a shell on this machine, and this page is where to find out which one to run and what to type.

Nothing here is a button, deliberately. There is no sign-in on this interface, so a button that ran one of these would be one anybody who can reach this port may press — and one of them sets a whole library aside. Pasting the line is the permission check: it needs a shell here.
